# Forest Pet Adopt
森林萌宠领养中心 🐰
> Scriptable 萌宠养成小游戏，适配 iPad / iPhone

## 📖 游戏介绍
领养小动物，喂食、抚摸，照顾你的森林萌宠，进度自动保存！

## 📱 运行要求
- 设备：iPad / iPhone
- App：Scriptable
- 系统：iOS / iPadOS 15 及以上

## 📥 使用教程
1. 打开 `forest-pet-adopt.js`，复制全部代码
2. 打开 Scriptable，点右上角「+」新建脚本
3. 粘贴代码，点右下角 ▶ 运行
4. 可以添加到桌面，一键打开游戏

## 🎮 游戏功能
- 🐰🐱🐶 三种宠物可以领养
- 🥕 喂食，增加饱食度
- ✋ 抚摸，提升好感度
- 📝 随时修改宠物名字
- 💾 自动存档，退出不会丢进度
